( 第五課：便利的生活 - ATM與網購取貨 )

[ ターゲット / 學習目標 ]

  1. ATMで振ふり込こむ (使用ATM領錢與匯款)
  2. コンビニで受うけ取とる (在便利商店取貨)
  3. 代引だいびきで支払しはらう (貨到付款的應對)

単語たんご 1：ATMと銀行ぎんこう (ATM與銀行)

  • 下おろす / 引ひき出だす 提款、領錢
  • 預入あずけいれ 存款、存錢
  • 振ふり込こむ（振込ふりこみ） 匯款、轉帳
  • 口座こうざ 銀行帳戶
  • 残高ざんだか照会しょうかい 餘額查詢

単語たんご 2：ネット通販つうはん (網購與取貨)

  • ネット通販つうはん 網路購物
  • 受うけ取とる 領取、取貨
  • 代引だいびき（代金引換だいきんひきかえ） 貨到付款
  • 送料そうりょう 運費
  • 不在票ふざいひょう 不在家聯絡單 (物流投遞失敗時的單子)

(在便利商店取貨，並且用貨到付款支付。)

文法ぶんぽう 1

〜てから

( 做完...之後才... / 強調先後順序 )

動作の順番（じゅんばん）を強調する時に使います。（N4文法）

動詞て形 ＋ から
(強調動作的順序，表示「一定要做完前面那件事，才接著做後面的事」。機器操作時極常使用。)

順番を守ろう！ (遵守先後順序吧！)

「〜てから」を使って、文を繋げてください。

1. 振込ふりこみが終おわります。➔ レシートを取（と）ります。
➔ 振込ふりこみが ＿＿＿＿＿＿＿＿＿＿ 、レシートを取（と）ってください。
(匯款結束後，請拿收據)

2. 荷物（にもつ）を確認（かくにん）します。➔ お金（かね）を払（はら）います。
➔ 荷物（にもつ）を ＿＿＿＿＿＿＿＿＿＿ 、お金（かね）を払（はら）います。
(確認完包裹後，才付錢)

順番を守ろう！ 解答

「〜てから」を使って、文を繋げてください。

1. 振込ふりこみが終おわります。➔ レシートを取（と）ります。
➔ 振込ふりこみが 終おわってから 、レシートを取（と）ってください。
(匯款結束後，請拿收據)

2. 荷物（にもつ）を確認（かくにん）します。➔ お金（かね）を払（はら）います。
➔ 荷物（にもつ）を 確認かくにんしてから 、お金（かね）を払（はら）います。
(確認完包裹後，才付錢)

文法ぶんぽう 2

〜までに

( 在...期限之前完成 )

期限（きげん）を表（あらわ）します。（N4文法）

その時間よりも前に、動作を終わらせるという意味です。
(表示期限。也就是在該時間點之前，必須把某個動作做完。常見於繳費、取貨期限。)

名詞（時間/日付） ＋ までに

例れい：明日（あした）の15時（じ）までに振ふり込こんでください。

期限を守ろう！ (遵守期限吧！)

請將以下期限填入空格中。

  • 金曜日（きんようび） (星期五)
    ➔ 金曜日            荷物（にもつ）を受（う）け取（と）ります。
  • 今日（きょう） (今天)
    ➔ 今日            振ふり込こんでください。

期限を守ろう！ 解答

請將以下期限填入空格中。

  • 金曜日（きんようび） (星期五)
    ➔ 金曜日 までに 荷物（にもつ）を受（う）け取（と）ります。
  • 今日（きょう） (今天)
    ➔ 今日 までに 振ふり込こんでください。

(不好意思，我想領網購的包裹。)
店員てんいん： はい、お名前なまえと番号ばんごうをお願ねがいします。
(好的，麻煩給我名字和編號。)
林： 林（りん）です。番号は「1234」です。
(我姓林。編號是1234。)

(是這件。因為是貨到付款，總共2500圓。)

会話かいわ 2：ATMの使つかい方かた (詢問ATM用法)

林： 田中たなかさん、ATMで振ふり込こみをしたいんですが、やり方（かた）を教（おし）えていただけませんか。
(田中先生，我想用ATM匯款，能教我怎麼用嗎？)
田中たなか： いいですよ。まず、カードを入（い）れてから、「振込ふりこみ」のボタンを押（お）します。
(好喔。首先，插入卡片後，按下「匯款」的按鈕。)
林： なるほど。手数料てすうりょうはかかりますか。
(原來如此。需要手續費嗎？)
田中たなか： はい、かかります。最後（さいご）に確認（かくにん）画面（がめん）が出（で）ますよ。
(對，需要。最後會出現確認畫面喔。)
